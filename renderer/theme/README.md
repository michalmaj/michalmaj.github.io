# Visual system v1

Stylesheets for every build of the site. The pipeline copies them into each build
(`stylesheets/teaching-hub/`) and the renderer links them through `extra_css`.
They work with Zensical and with MkDocs + Material, which share the same `--md-*`
variables and class names.

- `tokens.css`: design tokens (colours, fonts, radii) for the light and dark schemes.
- `theme.css`: maps the tokens onto the renderer theme and styles the components.
- `space-<space>.css` (optional): overrides for one space only, for example a
  different accent. It is linked only in that space's builds.

Direction: modern editorial / technology. The design uses a warm neutral page, dark
type, one restrained teal accent, thin borders instead of shadows, a serif display
face for page titles and system sans-serif for text. It has no gradients, no glass
effects and no decorative animation.

## Colour

Colours are named by role, and components use only these tokens. Every text pair meets
WCAG 2.2 AA (4.5:1), and component borders and focus indicators reach at least 3:1.
`tests/test_theme.py` checks every pair in both schemes.

## Typography

All fonts are system fonts or fonts already installed on the device. The site makes
no font requests to other hosts.

| Token | Use | Stack |
|---|---|---|
| `--th-font-text` | text, navigation, headings h2–h4 | `system-ui`, `-apple-system`, `Segoe UI`, `Roboto`, … |
| `--th-font-display` | page titles (h1) | `Iowan Old Style`, `Charter`, `Palatino Linotype`, `Georgia`, `Noto Serif`, serif |
| `--th-font-mono` | code, language badges | `ui-monospace`, `SF Mono`, `Cascadia Code`, `JetBrains Mono`, `Menlo`, `Consolas`, … |

- Body text is about 17 px with 1.7 line height. Paragraphs and lists are limited to
  about 72 characters per line (`--th-measure`).
- Small uppercase labels with wide letter spacing (eyebrows) mark set numbers and
  material lists.

## Components

| Component | Markup (generated by the pipeline) | Notes |
|---|---|---|
| Page type | `<div class="th-page" data-th-page="…" hidden>` | Scopes page-specific rules: `home`, `catalog`, `course`, `task-set`, `guide`, `licensing`. |
| Page bar | `.th-pagebar` | Breadcrumbs on the left, language switch on the right; stacks on phones. |
| Breadcrumbs | `<nav class="th-breadcrumbs" aria-label="…">` | Navigation landmark; the separators are hidden from screen readers. |
| Language switch | `a.th-lang-switch[lang]` | Pill link to the other language. |
| Cards | `.th-cards` › `.th-card` | Space, course, task set (`.th-card--set` with `.th-eyebrow`) and guide cards. The title link covers the whole card. |
| Lead and meta text | `.th-lead`, `.th-meta`, `.th-card__meta` | Course summary, estimated time, task count. |
| Materials | `.th-materials` (`--task` under a task), `.th-repos` | Bordered list. Each row shows the label link, the repository name and badges. |
| Badges | `.th-badge--lang`, `--ref`, `--status`, `--optional` | Language (`PL`/`EN` with a visually hidden "material language" label), Git ref, repository maturity, optional task. |
| Tasks | `h3[id]` on task set pages | Separated by a rule; the anchor ids stay stable. |
| Archived and draft notices | admonitions `warning` and `danger` | Amber and red token pairs. |
| Code, tables | standard Markdown | Syntax highlighting with token colours; tables scroll inside their container on small screens. |
| Header, navigation, search, footer | renderer theme | Neutral surface header, accent for the active page, pill search field, licensing footer. |

Screen-reader-only text uses `.th-sr`.

## Light and dark mode

The renderer's native colour scheme toggle cycles through system, light, dark and back
to system. The pipeline generates it per build, with labels from `data/i18n/`.
The default follows `prefers-color-scheme`. The visitor's choice is remembered by the
theme's own script; no JavaScript is added.

## Accessibility

- Keyboard focus is a 2 px outline in `--th-focus` on every interactive element.
- Links are underlined in text, so they are not distinguished by colour alone.
- Status (language, optional, archived, maturity) is always shown as text.
- `prefers-reduced-motion: reduce` disables transitions and animations.
- Layout is checked at 390 px (phone), 820 px (tablet) and 1440 px (desktop).

## Space accents

Each space may define `space-<space>.css` that overrides only the accent group:

```css
[data-md-color-scheme="default"] { --th-accent: …; --th-accent-strong: …; --th-accent-soft: …; --th-accent-on-soft: …; --th-focus: …; }
[data-md-color-scheme="slate"]   { … }
```

Any new colour must keep the contrast pairs listed in `tests/test_theme.py`.
